# Demo

Interactive demo with complete creative freedom on the concept; the concept and tooling are still to be decided. It imports the real algorithms from `dtc` (`pip install -e ".[demo]"` from the project root) and can also replay JSONL traces from `data/traces/` (see [../docs/DATA_FORMATS.md](../docs/DATA_FORMATS.md)).

Put the entry point in `app.py` and shared helpers in `components/`.
